# 📊 Financial Dashboard - Streamlit Project

An interactive Financial Dashboard built using Python, Streamlit, SQL, Excel, and Data Science libraries.  
This project visualizes sales, profit, cost, category analysis, regional analysis, clustering, forecasting, and business insights using attractive charts and dashboards.

# 🚀 Features

- 📈 Revenue Analysis
- 💰 Profit & Cost Analysis
- 🌍 Region-wise Sales Insights
- 🛒 Category-wise Performance
- 📊 Interactive Charts & Graphs
- 🤖 Machine Learning (Clustering)
- 📉 Forecasting & Trend Analysis
- 🎨 Custom CSS Styled Dashboard
- 📂 Excel & SQL Data Integration
